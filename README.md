## 📖 项目简介

本仓库记录了日常前端进阶与面试深造过程中的经典手写代码与算法实现，涵盖 JavaScript 运行机制、高阶函数、异步控制、DOM 特效及常见数据结构。

---

## 📚 精选题解与代码索引

### 1. JavaScript 底层机制与手写实现
- `_new函数.html`：手动模拟 `new` 操作符实例化流程
- `vue响应式原理.js`：手写极简响应式观察者模式（Object.defineProperty / Proxy）
- `红绿灯promise.html`：基于 Promise / async-await 实现交通红绿灯交替控制器
- `柯里化.js`：高阶函数柯里化（Currying）与参数复用
- `高阶函数.js`：手写 map、filter、reduce 等高阶函数
- `深度克隆对象数组.js`：处理循环引用的深拷贝算法

### 2. 经典数据结构与算法
- `树结构.js` / `树结构.html`：列表与树形结构双向转换算法
- `权限递归菜单.js`：路由与动态权限列表递归匹配过滤
- `洗牌算法.js`：Fisher-Yates 均匀洗牌与随机抽奖实现
- `冒泡排序.js`、`扁平化.js`、`数组对象去重.js`、`输出质数.js`

### 3. 交互与动效实战
- `CSS 滚动进度条.html`：纯 CSS 实现网页阅读进度条
- `断开文字特效.html`：趣味文字断裂动效
- `弹幕效果demo.html`：轻量弹幕发射与滚动渲染
